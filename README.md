## 📖 How to Use It (Step-by-Step)

### Format a Single File

1. Open the application.
2. Click **"Choose File"** (or drag-and-drop your `.lua` file into the window).
3. Click the **"Format"** button.
4. The tool creates a new, cleaned-up version of your file in the same folder. The original file stays untouched—you get a new file with `_formatted` added to the name (e.g., `game.lua` becomes `game_formatted.lua`).

### Format an Entire Folder

1. Open the application.
2. Click **"Choose Folder"**.
3. Select any folder on your computer.
4. Click **"Format All"**. The tool scans every `.lua` and `.luau` file inside, formats each one, and saves the clean versions next to the originals.

### Pro Tips

- **Test first:** Try it on a backup copy of your code before formatting your main project.
- **Check the output:** Open the formatted file and compare it to your original to see the improvements.
- **Use on any project:** This tool works with any Lua code, not just Roblox—game mods, scripts, configuration files, anything.

## 🛠️ Troubleshooting

**Problem:** The application won't open.  
**Solution:** Right-click the `.exe` file and select "Run as administrator." If that doesn't work, make sure you extracted the ZIP fully before running.

**Problem:** I get a "Windows protected your PC" message.  
**Solution:** Click "More info," then "Run anyway." This happens because the tool isn't signed with a digital certificate, which is common for open-source software.

**Problem:** The tool doesn't format my file.  
**Solution:** Make sure your file has the `.lua` or `.luau` extension. Rename it if needed. Also check that the file isn't read-only (right-click the file → Properties → uncheck "Read-only").

**Problem:** I lost my original file.  
**Solution:** The tool never deletes or overwrites originals. Your original file is still in the same folder—look for the new file with `_formatted` in its name.
